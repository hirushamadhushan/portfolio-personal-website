Project Editor

Add, edit and reorder the cards in the Work section — without touching HTML.

How this works. Your portfolio is a static site, so this page can't save anything by itself — it writes the file for you and you commit it.
  1. Add or edit your projects below.
  2. Click Download projects.js.
  3. Move the downloaded file into your js/ folder, replacing the old one.
  4. git add . && git commit -m "add project" && git push — live in about a minute.
This page is never linked from the site. It's safe if someone finds it: there's nothing to save and nothing to break. Delete admin.html before deploying if you'd rather not ship it.
